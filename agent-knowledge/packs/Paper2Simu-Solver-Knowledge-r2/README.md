## 材料和覆盖

共 174 项、169 个产生技术卡的实质来源、5 项导航。提炼 106 条条件规则、2 张概念卡和 1 张公式卡。规则中 100 条核心语义获独立来源核对，其余 6 条列为 candidate。

89 份培训 PDF（2,438 页）逐页做原生提取与页面渲染，9 份 PPTX（320 张）按演示顺序提取。3 份图像型讲义另作全页 OCR，引用页有人工目读。11 本手册（19,660 页）建了页级文本索引；正式引用的手册页逐条记录。12 个官方专题、2 个本机安装件及 46 份技能文档用于对照。

[来源及哈希](source-index.json) · [覆盖明细](coverage.json) · [审查记录](review.json) · [验证结果](validation-report.md)。r2 专注求解器知识，可与既有 r1 的仿真验证、DOE 和多目标优化三包配合使用。
