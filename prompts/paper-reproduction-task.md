# COMSOL / Fluent 论文复刻任务 prompt

本文件是 Paper2Simu **skill 包内**统一验收规范。论文复刻时由 agent **从本包自动加载并遵循**，无需人工每轮粘贴全文。人只需填写下方**任务卡**（及必要授权）。Paper2Simu skill 本体只负责连接、建模、执行和留证；门槛与推理规则以本文件及 [`conditional-calibration.md`](conditional-calibration.md) 为准。门槛是项目选择，不是厂商通用标准。

非论文复刻的纯执行任务：不要仅因加载 skill 而激活本文件。

## 任务卡

- 软件（COMSOL / Fluent 二选一）、主机、MCP provider/session、版本及模块：……
- 原文、补充/勘误、已有模型及可用外部来源：……
- 目标工况、重建范围、简化条件、输出目录：……
- 主要指标：记录评分定义版本，每项写 case/metric ID、论文参考值、单位与温标、页/表/图、逻辑选区、公式、平均/积分定义、时间窗口、符号及归一化方式。网格或几何变化后，按同一逻辑选区重新确认实体并留证。
- 默认论文指标容差：每个指定主要指标、每个指定工况相对误差 **严格小于15%**；可在运行前显式覆盖。
- 多指标综合目标：各相对误差项用 \(z_i=e_i/\tau_i\)，绝对容差项用 \(z_i=|S_i-D_i|/a_i\)。冻结各项门槛后计算 \(J=\max_i z_i\)，每项严格 \(z_i<1\) 才达标。
- 零值/近零范围与绝对容差：按指标预先填写。
- 守恒：适用方程、边界、源/汇、储存、时间范围、归一化尺度、容差及理由：……
- 网格/时间步：目标指标、加密方案、判据及理由：……
- 预算：运行时限、内存/核数、最大求解数、修复轮次、网格及敏感性预算、**条件校准最大联合求解数**、**tentative 变量上限**：……
- 已授权的运行、条件假设、输出和可逆修复范围：……
- 留出验证计划（另一流量/结构/指定数据，并标明原文模拟或独立实验）：……
- 校准保护项及可辨识尺度：……（例如主要指标已经达标的项、可比较保存解中观测到的数值或提取扰动）。

科学容差未填时，不暗中使用通用常数。agent 应根据量纲、指标用途、预期精度和算力提出有理由的值，在观察比较结果前固定。预算缺失时先提出保守且可编辑的预算，继续授权范围内的独立准备。需要用户决定的关键范围或授权保持待确认，时间经过不代表同意。

## 目标与状态

尽可能完成可信、可追溯、可继续运行的重建，不要求文章提供全部软件设置。目标是**接近论文指定指标**（条件可取），不是证明已找回作者全部软件设置。分别报告：执行及原生终止；数值/物理检查；逐点论文匹配；直接复刻 / 条件复刻 / 校准结果。

每项检查用 PASS / FAIL / BLOCKED / NOT_RUN 并附证据。没有预定判据只报告数值，不报 PASS。求解完成不等于复刻通过；指标达标而必要检查缺失，应报告“指标达到，验证未完成”。原生求解失败不能被条件通过覆盖。只有所有声明必要检查和主要指标满足要求，才可在明确范围内声称通过。条件复刻不得包装成原文真实设置。主动跳过记 SCOPE_CHANGED，未执行记 NOT_RUN。

## 一眼对照板 REPRODUCTION_DASHBOARD（必做）

最终交付与阶段小结都必须用下面四块表**一眼展示**进展；底层仍写 INPUT_LEDGER / TRIAL_MATRIX / QOI_CONTRACT，但聊天与报告首屏不得只给散文或一句 PASS。未执行的格填 `NOT_RUN` / `—`，禁止把缺失结果填成 0 或“已对齐”。

| metric_id | 工况 | 论文 benchmark（值+单位+出处） | 复刻输出（值+单位+run/dataset） | e 或绝对误差 | 门槛 | 状态 | 最佳 trial |
|---|---|---|---|---|---|---|---|
| … | … | … | … | … | <15% 或任务覆盖 | PASS/FAIL/… | T0xx |

对照板下方用三行摘要：

1. **重建类型**：直接 / 条件 / 校准；锁定输入摘要；当前 \(\theta\) 或 \(\Theta_{\mathrm{feasible}}\)。
2. **最佳可比较点**：`best_comparable_trial` 的 J、超限项、模型/网格身份。
3. **未闭合项**：NOT_RUN 检查、未独立验证的拟合、冲突证据、下一步最小动作。

校准进行中也要更新 C/D；失败交付同样填满四表。详细字段与事件格式见 [输入重建操作卡](paper-input-reconstruction.md)。

## 输入台账 INPUT_LEDGER（必做）

先按 [文献输入重建与迭代记录](paper-input-reconstruction.md) 建立证据定位、依赖关系、假设卡和逐轮记录。来源、调控角色与拟合状态分别保存；`derived` 仅在其依赖与推导条件确定时锁定，否则随根输入传播不确定性。官方默认值不证明作者使用它。下表是兼容旧台账的简写，以这些区分解释。

在求解与校准前建立并随任务更新台账。每行至少包含：

`id | name | value | unit | origin | layer | prior_box | affects_QoI | notes`

**origin（来源类型）**：`paper_reported`、`derived`、`software_documented`、`external_reference`、`inferred`、`fitted`。

**layer（调控层）**：

| layer | 含义 | 可否为过线而调 |
|---|---|---|
| `lock` | 论文明确，或依赖与推导条件均确定 | 否 |
| `software_doc` | 安装版官方文档默认/推荐的来源标记 | 数值项归 numerical；未明确的物理选择可有据归 tentative |
| `tentative` | 论文未消歧、带物理先验盒的假设 | **唯一可调集** |
| `numerical` | 网格/阶次/稳定化等 | 只估数值不确定，不作贴合旋钮 |
| `fitted` | 校准得到的值或区间 | 产物，不得回标为 paper_reported |

依次检查原文/作者补充与勘误；由已知几何、定义、量纲、守恒或无量纲关系推导（展示公式和条件）；安装版本官方文档/材料库及权威物性；相关权威论文的适用范围；最后给出有物理依据的有界假设。明确文字表格优先于同一量的示意图估计，但要核对对象/工况。软件默认不等于作者设置。曲线数字化保留误差，示意图不充当精确尺寸。

问题可定义且已授权时继续条件建模，不因“非原文直接给出”放弃。可解释、低影响的补充可按任务授权采用；影响未知时不得冒称低影响。后处理定义/选区错误先修，不进入校准。关键量无法给出合理范围或无法定义方程/边界时，集中询问，只阻塞依赖它的操作，继续其他准备或工况。

## 保存解优先审计

先核对已保存的 run、model revision、mesh、study/solver、solution/dataset 和文件身份。用保存解复算 QoI 和必要守恒量，读回激活的物理、表达式、实体和通量。对照论文对象与工况，区分主论文输出、引用验证算例和诊断分支。为能量问题记录控制体、外法向符号、热量和总能量各自的输运、源项、功项、储存与实际使用的归一化分母。分别保留直接边界表达式积分、可信原生通量和梯度重构（适用且可得时）。缺失证据记 NOT_RUN 或 BLOCKED，并继续可开展的检查。

发现评分定义错误时标明原文依据、升级评分版本，优先以该版本重评可比旧解，不跨评分版本排名。维修有效设置或纠正计算域应生成新基线并重做受影响检查。额外求解必须落在授权和任务预算内。

## 条件校准与可行区间

当基线超限且存在 `tentative` 变量时，遵循包内操作卡 [`conditional-calibration.md`](conditional-calibration.md)。摘要要求：

1. 完成保存解审计，登记唯一可调集合、数值门控和留出数据。
2. 默认小预算端点 OAT。只有明确要检验内点可行性、局部非单调性或可行点之间的变化时才追加中点。
3. 使用固定评分版本和同一归一化目标。每轮读回实际改动，复用匹配解或通过已授权 MCP 唯一提交。
4. 维护 **TRIAL_MATRIX** 和 **FEASIBLE_SET**，记录 KEEP、REVERT、HOLD 或 FAILED，以及检查、身份和原始值。
5. 分别报告实测通过点、阈值括区和候选连续区间。多组均达标则报告不可辨识。
6. 冻结拟合输入后执行留出计划。校准数据不能兼任独立验证。
7. 禁止用诊断热源、任意接触热阻、事后改参考/平均方式过线。

校准需记录拟合变量、先验盒、目标数据和尝试次数。不得为通过而事后改参考、删点、改平均方式或无依据调参。

## 原生求解与稳定性

以实际配置并观察到的商业软件原生停止标准为迭代收敛依据，保存配置、停止原因、日志、警告和主要物理量监控。完成任务、写出文件、退出码成功不自动等于收敛。

不附加无出处的统一残差门槛。额外残差/平台诊断用于排查，只有本任务事前明确要求才成为验收条件。检查目标量随迭代/时间的变化；非定常/周期问题用预定统计窗口，不要求非稳态物理量恒定。明显发散、非物理解或统计状态不足时记录问题并在预算内诊断。

## 守恒：检查当前模型自身

比较当前模型进出通量、源/汇和储存，不要求匹配论文未公开的守恒残差。质量、能量等分别记账，包含适用的导热、对流、辐射、相变、压力/功、瞬态储能，说明符号单位。核对原生通量提取的边界、域和精度。

声明平衡缺口和非零且物理合理的归一化尺度；净输入接近零时不用其作分母。容差按用途事前确定，不自动采用论文匹配15%，也不默认10%/20%。缺项不当零，未提取不当通过。不能仅凭简化焓差与热源不符就断言耦合错误。明显无法解释的不平衡需要诊断，能求解不能豁免。

## 网格与时间离散

预算内先比较两套有实质加密且物理设置一致的网格，记录单元/自由度、局部分辨率/壁面处理及全部主要指标变化。称为网格敏感性；两套网格不自动给出GCI、离散误差区间或网格无关性证明。

变化较大、非单调、接近任务卡门槛或结论改变时，按预算增加网格/时间步检查，或如实报告不确定。不能选择最接近论文的网格来宣称验证。计算GCI/拟合不确定度时另行满足该方法条件；普通复刻不自动要求特定方法论文的所有网格配置。非定常结果按目标量考虑时间步敏感性，预算不足不能伪造通过。

## 逐点论文误差

非近零且适合相对比较的参考值：

`relative_error = abs(simulation - reference) / abs(reference)`

每个指定指标/工况要求 `< 0.15` 或任务卡显式覆盖值；等于门槛不通过。不能用平均误差掩盖超限点。曲线取点、对齐、插值事前固定。温度事前声明绝对温度还是温升，不能借摄氏零点或换单位改变误差。

零值/近零参考使用预定绝对容差及单位；无有效判据记 NOT_RUN，不能除零或临时挑分母。来源不确定性、数字化误差、输入假设、离散敏感性分别报告，未经依据不合并总误差。即使单点低于15%，也说明合理输入范围是否跨越门槛（见 FEASIBLE_SET）。

## 执行、恢复和交付

使用已选MCP路线，核查实际选区、边界、材料、耦合及结果身份。遵守预算，保留失败基线；修复记录修改、理由和受影响检查。参数/网格变动后重做依赖检查，不混用旧数据、不覆盖原始材料、不干扰他人任务。

交付原生模型（含有价值的失败/部分模型）、实际调用/脚本、日志、**REPRODUCTION_DASHBOARD**（SOURCE_MAP / BASELINE_INPUTS / ITERATION_DELTA / OUTPUT_VS_BENCHMARK）、**INPUT_LEDGER**、逐点对比表、**TRIAL_MATRIX**（若做了校准）、**FEASIBLE_SET**（若适用）、守恒收支、网格/时间步比较、未解决问题及继续运行设置。附run/model/mesh/study/solution/dataset身份和文件校验信息。重开未执行写NOT_RUN；不只交截图或一句PASS。

最终报告先给出对照板四表，再说明执行结果、证据与假设、主要指标误差与 \(J\)、检查结果、条件可行区间与未验证项、文件清单。检索token节省、RSI改进、软件开发验收只在另行要求且实测时报告。

条件复刻通过时使用操作卡规定的交付句式：写明锁定输入、文档默认、\(\theta\in\Theta_{\mathrm{feasible}}\)，并声明可行区间≠作者设置唯一还原。
